        Inhalte blockieren

        Eine Web-App kann selbst nichts sperren – aber dein Handy kann es, in 2 Minuten:

        Android
        1. Einstellungen → Netzwerk & Internet → Privates DNS
        2. „Hostname des privaten DNS-Anbieters“ wählen
        3. Eintragen: family-filter-dns.cleanbrowsing.org → Speichern
        iPhone
        1. Einstellungen → Bildschirmzeit → Beschränkungen aktivieren
        2. Inhaltsbeschränkungen → Webinhalte → Websites für Erwachsene beschränken
        3. Bildschirmzeit-Code von einem Freund setzen lassen
        Windows-PC
        1. Einstellungen → Netzwerk → Adapter → DNS-Serverzuweisung → Bearbeiten → Manuell
        2. IPv4 DNS: 185.228.168.168 und 185.228.169.168
